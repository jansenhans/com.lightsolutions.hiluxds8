Automatic light naming

Homey API key

Needed to rename lights automatically (apps cannot rename devices on their own). Create a key via Homey Settings → API Keys with full access to Devices, and paste it here.

Presence simulation

Rooms follow a daily routine based on their type, sunset and the weekday — different every day. Also available as Flow cards. Leave a room out via its group's settings.

Wi-Fi access points

Each light reports which access point it is connected to. Give them a name (e.g. "Orbi router", "Satellite hall") and every light shows it instead of the address.
